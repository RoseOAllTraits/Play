# Artwork Provenance

The 48 local WEBP illustrations were generated for this project on 25 October 2026 using Websim image generation, without uploaded reference images or third-party source art. Six original faction-themed 4-by-2 atlases were cropped into individual images and resized to 336 by 224 pixels. There are eight illustration subjects for each of six circles.

Files use art/F-T.webp: F is the faction index in catalog.json; T is the type index. Each card record explicitly references its illustration. Procedurally generated cards use a per-card hue variation. These are 48 shared illustrations, not 56,600 unique paintings. All illustrations are local assets and need no runtime image-generation service.

Subjects: Neighbor, Spark, Ritual, Tool, Habit, Homestead, Envoy, Undertaking. Original factions: Moss Bureau, Ember Kitchen, Tide Archive, Copper Guild, Violet Post, Chalk Assembly. Prompts asked for cozy surreal fantasy inspired by ordinary household errands, with no existing franchise characters, logos or commercial card-game imagery.
